# Before We Pay Twice — Invoice Guardian

This package contains:

- `Invoice_Guardian_AI.ipynb` — incremental Google Colab teaching notebook with saved outputs.
- `app.py` — interactive Streamlit illustration app.
- `invoice_guardian.py` — deterministic synthetic accounting-control simulation.

Run locally with `streamlit run app.py`. The notebook links to the project-name deployment at `https://invoice-guardian-ai.streamlit.app`.

All suppliers, invoices, purchase orders and bank identifiers are fictitious. The simulation supports accounting education; it does not accuse suppliers of fraud or authorize real payments.

# AI-Based Engine Operating Condition Classification with an MLP

An educational Mechanical Engineering + tabular Deep Learning project. Seven current sensor readings feed a compact MLP that classifies Normal, High Load, Overheating, Inefficient Operation, or Abnormal.

Recommendations are simulated, not machinery-control instructions. Real use requires engine-specific limits, calibrated data, validated labels, temporal checks, out-of-distribution handling, qualified review, and approved procedures.

Files include `Engine_Operating_Condition_MLP.ipynb`, Streamlit `app.py`, shared `bridge.py`, `story.py`, and `tools/build_notebook.py`. Every stage follows the linked Smart Construction structure. Replace `https://engine-operating-condition.streamlit.app` after deployment and rebuild.

The Streamlit companion contains a catalog of 32 dedicated technical illustration scenes distributed across all teaching stages.

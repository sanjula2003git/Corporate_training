# Indian Legal Timeline Assistant

An educational Streamlit prototype that screens the incident date, identifies the starting Indian criminal-law framework, compares IPC and BNS theft provisions, flags missing facts and generates a common cited issue report.

## Run

```powershell
cd "C:\Users\fersa\Corporate Training\Indian_Legal_Timeline_Assistant"
python -m pip install -r requirements.txt
streamlit run app.py
```

This is not legal advice, a judgment or a sentencing tool. Human legal review is mandatory.

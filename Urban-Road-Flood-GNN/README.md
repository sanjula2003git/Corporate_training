# Urban Road Flood-Risk Prediction Using Graph Neural Networks

A Civil Engineering + Graph Deep Learning project. Five features are stored on each virtual road node, road connections form graph edges, and a two-layer GCN predicts Low, Medium, or High flood risk for every road before ranking the likely flooding order.

The project uses a pure-TensorFlow normalized-adjacency implementation and requires no specialized GNN package. It is an educational synthetic network, not an emergency-routing or traffic-control system.

Files include `Urban_Road_Flood_Risk_GNN.ipynb`, Streamlit `app.py`, `bridge.py`, `story.py`, 32-scene `illustration_gallery.py`, and `tools/build_notebook.py`. Replace `https://urban-road-flood-gnn.streamlit.app` after deployment and rebuild.

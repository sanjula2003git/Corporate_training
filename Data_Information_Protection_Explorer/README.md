# Understanding Digital Data Explorer

An interactive Streamlit concept lab covering the complete **Unit 1.1: Understanding Digital Data** curriculum and ending with connections to later course units.

## Run locally

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The app covers meaning of data, data vs information, structured and unstructured data, files and databases, applications and workloads, the data lifecycle, real-world examples, later-unit connections and a knowledge check.

# Power-Line Fault Section Identification Using Voltage–Current Waveforms and a 1D CNN

An Electrical Engineering + Deep Learning teaching project. A 1D CNN receives a 500×2 voltage/current record and classifies a simulated 20 km line into four 5 km inspection regions.

## Safety boundary

This synthetic educational model is not protection equipment, a relay function, a trip command, or a field-validated fault locator. Real deployment requires validated network models, synchronized measurements, instrument-transformer behaviour, fault studies, communications, independent testing, protection coordination, cybersecurity, qualified engineers, and utility approval.

## Files

- `Power_Line_Fault_Section_1D_CNN.ipynb`: runnable Colab notebook.
- `app.py`: interactive Streamlit line and waveform illustrations.
- `bridge.py`: shared nine-stage teaching registry.
- `story.py`: fault-line and waveform figures.
- `tools/build_notebook.py`: reproducible notebook generator.

Every stage uses the Smart Construction five-part structure with illustration and navigation holders. Replace `https://power-line-fault-location.streamlit.app` after deployment and rebuild.

The Streamlit companion contains a catalog of 32 dedicated technical illustration scenes distributed across all teaching stages.

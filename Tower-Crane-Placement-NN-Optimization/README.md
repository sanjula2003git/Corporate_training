# AI-Based Tower Crane Placement Optimization Using a Neural Network Surrogate

A construction-planning teaching project. An MLP learns the exact candidate-location cost surface, a genetic algorithm searches the surrogate, and the best candidates are rechecked using exact weighted-distance, reach, obstacle, and safety-zone calculations.

This is not a crane selection, lift plan, structural design, collision study, or safety approval. Real planning requires crane specifications, capacities, load charts, foundations, tie-ins, air rights, slew restrictions, power-line clearances, sequencing, qualified planners, and regulatory review.

Files include `Tower_Crane_Placement_NN_Optimization.ipynb`, Streamlit `app.py`, `bridge.py`, `story.py`, 32-scene `illustration_gallery.py`, and `tools/build_notebook.py`. Replace `https://tower-crane-placement.streamlit.app` after deployment and rebuild.

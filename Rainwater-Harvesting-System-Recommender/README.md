# AI-Based Rainwater Harvesting System and Storage Capacity Recommendation Using MLP Optimization

This educational Civil Engineering project contains a linked Colab notebook and Streamlit companion. It uses a daily water-balance simulator to create training targets, an MLP surrogate to estimate useful annual rainwater supply, candidate-capacity optimization, and an interpretable system-type recommendation.

The Streamlit application includes 32 registered technical illustration scenes. The notebook contains nine linked Part 1–5 lessons, with a dedicated illustration holder immediately above each technical section.

This is a preliminary concept-screening simulation, not construction-ready design.

## Run

```text
pip install -r requirements.txt
streamlit run app.py
```

Replace the placeholder deployment URL in `tools/build_notebook.py` and rerun it when the Streamlit URL is available.

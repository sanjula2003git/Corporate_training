# Predictive Gearbox Vibration Control Using a 1D CNN

A Mechanical Engineering + Deep Learning teaching project. A 1D CNN extracts vibration-waveform features, fuses them with RPM, torque, temperature, and motor current, and predicts vibration 30 seconds ahead.

The 7 mm/s danger band is an educational project assumption. All responses are simulated, not industrial control instructions. Real use requires equipment-specific limits, calibrated sensors, validation across machines and loads, protection logic, qualified review, and approved procedures.

Files include `Gearbox_Vibration_Prediction_1D_CNN.ipynb`, Streamlit `app.py`, shared `bridge.py`, illustrations in `story.py`, and `tools/build_notebook.py`.

Every notebook stage follows the Smart Construction linked five-part structure. Replace `https://gearbox-vibration-prediction.streamlit.app` after deployment and rebuild.

The Streamlit companion contains a catalog of 32 dedicated technical illustration scenes distributed across all teaching stages.

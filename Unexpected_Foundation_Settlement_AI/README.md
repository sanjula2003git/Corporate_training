# Unexpected Foundation Settlement AI

One complete teaching project containing the Google Colab notebook and its interactive Streamlit illustrations.

## Project files

| File | Purpose |
|---|---|
| `Unexpected_Foundation_Settlement_AI.ipynb` | Beginner-friendly Colab notebook with synthetic data, model training, explanations, risk maps and uncertainty maps |
| `Unexpected_Foundation_Settlement_AI_Illustration.png` | Generated overview illustration embedded in the notebook |
| `app.py` | Interactive Streamlit illustration application |
| `bridge.py` | Plain-English content for the eight teaching stages |
| `story.py` | Virtual site, Random Forest model and Plotly illustrations |
| `smoke_test.py` | Route-level Streamlit test |
| `requirements.txt` | Python dependencies |
| `.streamlit/config.toml` | Streamlit visual theme |

## Run the Streamlit illustrations

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Use the notebook

Upload `Unexpected_Foundation_Settlement_AI.ipynb` to Google Colab and select **Runtime → Run all**.

## Safety boundary

The project uses simulated data for teaching. It cannot declare a structure safe, choose a foundation repair or replace qualified geotechnical and structural engineering review.

# Computer Fundamentals Explorer

A beginner-friendly Streamlit illustration for Unit 1.2: Computer Fundamentals.

## Run

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

The app teaches hardware, software, CPU, RAM, motherboard, storage, HDD vs SSD, input/output, peripherals, operating systems and the data processing cycle through labelled diagrams, interactions and everyday examples.
